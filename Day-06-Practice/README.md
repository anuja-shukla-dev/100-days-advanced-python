# Day 6 — Advanced OOP Practice & Interview Preparation

## 📌 Overview

Day 6 was dedicated to practicing and strengthening the Advanced OOP concepts covered during Days 1–5.

The focus was on implementing concepts through Python programs and testing conceptual understanding through interview-style questions.

## 🎯 Concepts Practiced

- Multiple Inheritance
- Method Resolution Order (MRO)
- Abstract Classes
- Composition
- Magic / Dunder Methods
- `super()`
- Diamond Inheritance

## 💻 Programs

### 1. Multiple Inheritance
Implemented a `CollegeStudent` class using multiple inheritance with `Student` and `College`.

### 2. MRO Practice
Created a diamond inheritance structure to understand how Python resolves methods using MRO and `super()`.

### 3. Abstract Class
Created an abstract `Shape` class and implemented `area()` in `Rectangle` and `Circle`.

### 4. Composition
Built a `Computer` using `CPU`, `RAM`, and `Storage` objects to demonstrate a HAS-A relationship.

### 5. Magic Methods
Implemented:

- `__str__()`
- `__add__()`
- `__eq__()`

using a `Book` class.

## 🧠 Key Learnings

- `super()` follows the Method Resolution Order rather than simply calling the direct parent.
- Multiple inheritance can create a diamond inheritance problem.
- Abstract classes define a common interface for subclasses.
- Composition represents a HAS-A relationship.
- Magic methods allow Python objects to interact naturally with built-in operators and functions.
