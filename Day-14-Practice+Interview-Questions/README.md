### Day 12 — Decorators

* Basic decorators

* Modifying function behavior without changing the original function

### Day 13 — Decorators with Arguments

  `decorator arguments → decorator → wrapper`

## 🏦 Final Mixed Practice — BankAccount

The final challenge combined multiple Advanced Python concepts into a single `BankAccount` class.

### Concepts implemented:

* Constructor and object initialization
* Encapsulation using `_balance`
* `@property`
* Operator overloading using `__gt__()`
* Class method using `create_account()`
* Static method using `validate_account_no()`
* Decorator using `transaction_logger`
* `*args` and `**kwargs`
* Function metadata using `__name__`
* Input validation
* Deposit and withdrawal operations

This challenge helped connect individual concepts into a practical Python program.
